## What each chapter contains

Every published lesson is designed to move from intuition to confident implementation:

- beginner-friendly motivation and precise learning objectives;
- mathematical derivations, equations, diagrams, and worked examples;
- reusable NumPy code with type hints, docstrings, and unit tests;
- Matplotlib visualisations and a companion notebook;
- ML applications, common mistakes, exercises, interview questions, and references.

## Learning philosophy

Machine learning becomes much less mysterious when its building blocks are visible. Rather than memorising library calls, we will ask:

1. What problem does this idea solve?
2. What does it mean visually and mathematically?
3. How can we implement and test the smallest correct version?
4. Where does that version appear inside a real ML system?

!!! tip "A useful way to study"

    Read the intuition first, reproduce the worked example by hand, then run the notebook. If a formula feels opaque, return to the diagram before moving on.
